# 教材助教 · 功能架构

版本 v1.1（2026-10-22）

把电子教材变成能对话的助教：问它书里怎么讲的，它答、给页码、把书上的图直接摆出来；它记得你在学什么、喜欢怎么讲。

**这份文档只回答「系统要有哪些功能、每个功能算做完了的标准是什么」。** 不写技术方案——选型、数据结构、接口、算法、代码组织都留到开发时决定。写死这些会误导后续开发。

---

## 1 使用场景

| 场景 | 用户做什么 | 期望看到 |
| --- | --- | --- |
| 复习 | 问「第 3 章抽样定理怎么推的」 | 答案 + 书上那段原文 + 那张图/那个公式 |
| 自学 | 问一个新概念 | 教材里的讲法，带页码，能点回原文 |
| 查漏 | 让 AI 就一章出几道题 | 题目、判分、错在哪、书上哪一节说的 |
| 日常 | 随手问、聊学习计划 | 不用重复自我介绍，它知道我在学什么 |

## 2 功能架构总览

| 域 | 一句话 | 优先级 |
| --- | --- | --- |
| A 教材库 | 把书放进去，能看见、能删 | P0 |
| B 检索问答 | 提问 → 从书里找 → 答，找不到就说找不到 | P0 |
| C 引用溯源 | 每个结论能追到书上的哪一段、哪张图、哪个公式 | P0 |
| D 学习辅助 | 章节摘要 + 自测出题 + 批改追问 | P1 |
| E 个性化记忆 | 记住你的偏好、身份、习惯、学习进度 | P1 |
| F 多人使用 | 几个同学各用各的，互不可见 | P1 |
| G 图片提问 | 发一张图（题目截图、书上某页、手写笔记）直接问 | P2 |

四个域构成主线：**A → B → C 做完就是一个能用的产品**，D、E、F 是在这之上的加厚，G 是独立的输入方式。

## 3 功能清单

### A 教材库

| 编号 | 功能 | 说明 | 完成标准 |
| --- | --- | --- | --- |
| A1 | 上传教材 | 支持 PDF / PPT；DOCX 也要能传 | 三种格式都能传成功，失败有原因提示 |
| A2 | 解析状态可见 | 上传后在列表里看到「解析中 / 可用 / 失败」 | 状态会推进，不会永远停在「解析中」 |
| A3 | 教材列表 | 看到书名、页数、解析状态 | 列表与实际文件一致 |
| A4 | 删除教材 | 删掉后相关问答不再引用它 | 删完问相关内容，不会冒出这本书的内容 |
| A5 | 重复上传不重复处理 | 同一个文件传两次，不产生两本 | 列表里只有一本 |
| A6 | 内容干净度 | 切出来的段落完整、不带页眉页码 | 抽 20 段，明显破碎/含页眉的不超过 3 段 |
| A7 | 图片与公式识别 | 书里的插图和公式能被找到并被引用 | 抽 10 张图，能和书上图号对上的 ≥ 7 |

### B 检索问答

| 编号 | 功能 | 说明 | 完成标准 |
| --- | --- | --- | --- |
| B1 | 针对教材提问 | 问书里的内容，答案基于这本书 | 10 个问题里，答案能对上原文的 ≥ 7 |
| B2 | 专有名词能搜到 | 术语、公式编号、缩写也要搜得到 | 拿 10 个术语/式号搜，能召回的 ≥ 8 |
| B3 | 多轮追问 | 「它的带宽呢」这类指代能接上上文 | 2 个多轮用例都能正确理解指代 |
| B4 | 教材里没有就明说 | 不编造、不硬答 | 5 个「书里没有」的问题，全部明确说没有 |
| B5 | 联网补充 | 教材没有且属于外部/时效信息时，主动联网 | 书里没有的时事类问题，会去搜而不是拒答 |
| B6 | 说得清在看哪本书 | 有多本书时知道该查哪本 | 指定书名提问，答案来自指定的书 |

### C 引用溯源

| 编号 | 功能 | 说明 | 完成标准 |
| --- | --- | --- | --- |
| C1 | 文字引用 | 每个结论标注它来自书上哪一段 | 引用能点开看到原文段落 |
| C2 | 页码真实 | 标注的页码、章节与书一致 | 抽查 10 条，页码错的 ≤ 1 |
| C3 | 图片直接显示 | 说「如图 3-4」时，图就出现在回答里，不用点链接 | 图在正文里显示，图号与书一致 |
| C4 | 公式直接显示 | 引用公式时显示书上原式 | 公式出现在回答里，与书上一致 |
| C5 | 刷新不丢 | 重新打开这个会话，引用和图还在 | 刷新后引用与图仍可点开 |
| C6 | 不硬凑引用 | 找不到出处的话不编引用 | 纯闲聊/推理的回答里不出现假引用 |

### D 学习辅助

| 编号 | 功能 | 说明 | 完成标准 |
| --- | --- | --- | --- |
| D1 | 章节摘要 | 就一章给出概览、要点、关键图表 | 抽 5 章，要点都能在原文找到依据 |
| D2 | 不超纲 | 摘要只用书上内容，不掺外部知识 | 抽 10 条要点，无依据的 ≤ 1 |
| D3 | 自测出题 | 就一章出 5 道题（选择/填空） | 20 道题里，题目合理、答案正确的 ≥ 16 |
| D4 | 批改 | 提交答案后判对错并给解析 | 判分与人工判分一致 |
| D5 | 错题追问 | 错了能问「为什么错」，答案回到书上某节 | 追问能指出所依据的段落 |
| D6 | 省着用 | 同一章重复查看摘要/题目不重复花时间 | 第二次打开秒出，内容一致 |

### E 个性化记忆

| 编号 | 功能 | 说明 | 完成标准 |
| --- | --- | --- | --- |
| E1 | 记住讲解偏好 | 说一次「先给结论再展开」，以后就这么讲 | 说过一次后，连续 5 轮都照做 |
| E2 | 记住身份与称呼 | 专业、年级、怎么称呼你 | 换个新会话不用重复介绍 |
| E3 | 记住学习情况 | 在学什么、卡在哪一章 | 新会话能接上「你上次问的是第 3 章」 |
| E4 | 记住生活类信息 | 作息、爱好、习惯（用户主动说的） | 相关话题里自然用上，不硬塞 |
| E5 | 进度可见 | 能看出自己在哪章问得多、哪章薄弱 | 问「我哪块弱」能给出具体章节 |
| E6 | 记得的都能看见 | 列出 AI 记住了什么，可删、可改 | 删掉某条后，它真的不再提 |
| E7 | 首次填写学习档案 | 新用户填专业/课程/目标/讲解偏好 | 填完第一轮对话就像认识你 |
| E8 | 不编记忆 | 说「你之前说过 X」时，X 必须真的记过 | 抽查 20 条「你之前说过」，失实的 = 0 |

### F 多人使用

| 编号 | 功能 | 说明 | 完成标准 |
| --- | --- | --- | --- |
| F1 | 邀请制注册 | 只有拿到邀请码的人能注册 | 没邀请码注册失败 |
| F2 | 教材互不可见 | 各人只看自己的书、图、摘要 | 用 B 账号访问不到 A 的任何内容 |
| F3 | 用量上限 | 每人书数、单本大小、每日提问次数有上限 | 超限时给明确提示，不卡死 |
| F4 | 防刷 | 登录与提问接口不会被反复调用拖垮 | 连续快速请求会被限制 |

### G 图片提问

| 编号 | 功能 | 说明 | 完成标准 |
| --- | --- | --- | --- |
| G1 | 对话里发图 | 提问时能附一张图，不用先存进教材库 | 发图 + 一句话，收到针对这张图的回答 |
| G2 | 看得懂图里有什么 | 读出图里的文字、公式、图形关系 | 抽 10 张（题目截图/书上页/手写），主要信息认对的 ≥ 7 |
| G3 | 拍书页能接着查 | 拍的是教材某页时，能连上这本书的上下文 | 拍一页后追问同节内容，答案与那页一致，页码对得上 |
| G4 | 图和问题能分开 | 一张图配多个问题，不用每次重传 | 同一张图连问 3 个问题，都基于这张图回答 |
| G5 | 发图不打乱上下文 | 连续发几张图，前面的对话不会被挤掉 | 发 5 张图后问前面聊过的内容，仍答得出 |
| G6 | 历史里图还在 | 重新打开这个会话，发过的图还能看到 | 刷新后图仍显示，不是占位符 |
| G7 | 传不了要说清楚 | 格式不对、太大、图糊了都明说原因 | 三种失败情况各给一句能看懂的原因 |

## 4 功能依赖

```
A 教材库 ──► B 检索问答 ──► C 引用溯源
                 │
                 ├──► D 学习辅助
                 ├──► E 个性化记忆
                 └──► G 图片提问

F 多人使用：独立，任何时候可加
```

- **A 不做完，B/C 没有意义**——书进不来，问答就是在空库上编。
- **C 依赖 B**：先有「找到哪段」，才谈「引用哪段」。
- **D、E、G 都吃 A 的内容和 B 的对话记录**，可以在主线跑通后并行。
- **G 里的 G3 单独依赖 A**：拍书页要接着查教材，得先有解析好的书；G1/G2 只靠看图就能做。
- **F 与主线无关**，几个人开始用之前补上即可。

## 5 优先级

| 级别 | 功能 | 理由 |
| --- | --- | --- |
| P0 | A1-A7、B1-B4、C1-C6 | 做完就是「能用的教材助教」 |
| P1 | B5-B6、D1-D6、E1-E8、F1-F4 | 好用、像助教、能给别人用 |
| P2 | G1-G7、讲解深浅随基础调整、跨书综合回答、复习计划 | 有价值但不做也成立 |

## 6 不做

- 扫描件 OCR（图片里的字认不出，遇到就明说）
- 把公式转成可编辑格式（书上什么样就显示什么样）
- 把统计图读成数据表
- 错题本与遗忘曲线复习（只保留作答记录）
- 掌握度百分比（不用模型猜「你掌握了 70%」）
- 公网开放、付费、多机构隔离

## 7 整体验收

一条线走完算完成：

1. 传一本 PDF、一套 PPT，都能解析成可用的内容；
2. 就教材问 10 个问题，答对 ≥ 7 个，每个答案能点回原文；
3. 问到图/公式时，图和式直接出现在回答里，页码与书一致；
4. 问 5 个书上没有的问题，全部明说没有，其中时事类会去联网；
5. 让 AI 出 5 道题、答一遍、错一题追问，能指回书上某节；
6. 换个新会话，它记得你的称呼、讲解偏好、上次学到哪；
7. 另一个账号登录，看不到上面任何东西。
